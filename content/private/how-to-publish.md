title: Как публиковать
---

Папка `private` на сайт не попадает. Здесь лежат эта справка и панель [[publications.base|Публикации]].

## Новая заметка

1. `⌘N`, имя файла пишешь по-английски: `how-i-train`. Из имени получится адрес `blog.borozdov.ru/how-i-train/`.
2. `F2` → `note`: шаблон добавит свойства.
3. В `title` пишешь заголовок по-русски. Его увидят на сайте: в заголовке, проводнике, поиске, ссылках.
4. Пишешь текст.
5. Готово? Сними галочку `draft`.
6. `⌘⇧S` (или палитра команд → «Git: Commit-and-sync»). Через 2–3 минуты заметка появится на сайте.

Число в строке состояния внизу показывает, сколько файлов ты ещё не опубликовал.

## Комментарии из Telegram

1. Опубликуй пост о заметке в @BorozdovBlog.
2. Скопируй ссылку на пост: `https://t.me/BorozdovBlog/12`.
3. Вставь её в `telegram_discussion` и нажми `⌘⇧S`.

Хватит и номера поста: `telegram_discussion: 12`. Комментарии появятся под заметкой, если у канала привязана группа обсуждений.

## Свойства

| Свойство | Что делает |
| --- | --- |
| `title` | Заголовок на сайте. Пустой: сайт возьмёт имя файла |
| `description` | Текст для поисковиков, превью в Telegram и RSS. Пустой: сайт возьмёт первые строки |
| `date` | Дата публикации. Сайт показывает её и сортирует по ней заметки. Перед публикацией поставь нужную |
| `tags` | Теги. Лучше по-английски: из тега получается адрес `/tags/sport/` |
| `draft` | Галочка стоит: заметки нет на сайте |
| `telegram_discussion` | Ссылка на пост в канале или его номер |

Необязательные, допиши сам, когда нужно:

| Свойство | Что делает |
| --- | --- |
| `updated: 2026-11-01` | Дата правки. Попадает в карту сайта для поисковиков |
| `aliases: [old-name]` | Старый адрес продолжит открываться и перекинет на новый |
| `permalink: /train/` | Свой адрес вместо имени файла |
| `enableToc: false` | Убирает оглавление справа |
| `comments: false` | Убирает комментарии |
| `noindex: true` | Страница открывается по ссылке, но поисковики её не видят |
| `socialDescription` | Отдельный текст для превью в соцсетях |
| `cssclasses` | Классы для особого оформления |

## Папки

Папка на сайте становится разделом. Имя папки тоже пиши по-английски: `notes`. Чтобы раздел назывался по-русски, положи в папку `index.md`:

```yaml
---
title: Заметки
---
```

## Что сайт понимает

Работают: ссылки `[[how-i-train]]` (сайт подставит русский `title`), `[[how-i-train|свой текст]]`, `[[how-i-train#Раздел]]`, вставки `![[how-i-train]]`, картинки `![[photo.png]]` из папки `attachments`, выноски `> [!tip]`, `==выделение==`, `%%комментарий%%`, теги `#sport`, формулы `$x^2$`, диаграммы mermaid, таблицы, сноски.

Не работают: холсты (canvas), базы (bases), кликабельные чекбоксы. Картинка превью у всех страниц одна, `socialImage` её не меняет.

## Важно

Репозиторий на GitHub публичный. Черновики и папку `private` сайт не показывает, но на GitHub их текст виден всем. Личное держи в другом хранилище.
