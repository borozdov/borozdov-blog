---

Папка `private` на сайт не попадает. Здесь лежат эта справка и панель [[publications.base|Публикации]].

## Новая заметка

1. `⌘N` и имя файла. Пиши как удобно, хоть по-русски: имя файла живёт только в Obsidian.
2. `F2` → `note`: шаблон добавит все свойства, `title` заполнится именем файла.
3. `title`: заголовок на сайте. Поправь, если нужен другой.
4. `permalink`: адрес по-английски, например `how-i-train`. Заметка откроется по `blog.borozdov.ru/how-i-train/`.
5. Пишешь текст.
6. Готово? Сними галочку `draft`.
7. `⌘⇧S` (или палитра команд → «Git: Commit-and-sync»). Через 2–3 минуты заметка появится на сайте.

Число в строке состояния внизу показывает, сколько файлов ты ещё не опубликовал.

## Комментарии из Telegram

1. Опубликуй пост о заметке в @BorozdovBlog.
2. Скопируй ссылку на пост: `https://t.me/BorozdovBlog/12`.
3. Вставь её в `telegram_discussion` и нажми `⌘⇧S`.

Хватит и номера поста: `telegram_discussion: 12`. Комментарии работают у постов, опубликованных после привязки группы @BorozdovBlogComments.

## Свойства

| Свойство              | Что делает                                                                                |
| --------------------- | ----------------------------------------------------------------------------------------- |
| `title`               | Заголовок на сайте: на странице, в проводнике, поиске и ссылках                           |
| `permalink`           | Адрес. `how-i-train` ляжет рядом с папкой заметки, `/how-i-train` в корень сайта          |
| `description`         | Текст для поисковиков, превью в Telegram и RSS. Пусто: сайт возьмёт первые строки         |
| `date`                | Дата публикации. Сайт показывает её и сортирует по ней заметки. Перед публикацией поправь |
| `updated`             | Дата правки. Уходит поисковикам в карту сайта                                             |
| `tags`                | Теги. Лучше по-английски: из тега получается адрес `/tags/sport/`                         |
| `draft`               | Галочка стоит: заметки нет на сайте                                                       |
| `telegram_discussion` | Ссылка на пост в канале или его номер                                                     |
| `comments`            | Сними галочку, и комментариев под заметкой не будет                                       |
| `enableToc`           | Сними галочку, и оглавление справа пропадёт                                               |
| `noindex`             | Поставь галочку: страница откроется по ссылке, но поисковики её не увидят                 |
| `aliases`             | Старые адреса. Они продолжат открываться и перекинут на новый                             |
| `socialDescription`   | Отдельный текст для превью в соцсетях                                                     |
| `cssclasses`          | Классы для особого оформления                                                             |

Пустой `permalink`: адрес возьмётся из имени файла. Если в имени кириллица, адрес получится нечитаемым, поэтому заполняй его.

## Папки

Папка становится разделом сайта, и её имя входит в адрес: `notes/how-i-train`. Называй папки по-английски. Чтобы раздел на сайте назывался по-русски, положи в папку `index.md`:

```yaml
---
title: Заметки
---
```

## Что сайт понимает

Работают: ссылки `[[Как я тренируюсь]]` (сайт подставит `title` этой заметки), `[[Как я тренируюсь|свой текст]]`, `[[Как я тренируюсь#Раздел]]`, вставки `![[Как я тренируюсь]]`, картинки `![[photo.png]]` из папки `attachments`, выноски `> [!tip]`, `==выделение==`, `%%комментарий%%`, теги `#sport`, формулы `$x^2$`, диаграммы mermaid, таблицы, сноски.

Не работают: холсты (canvas), базы (bases), кликабельные чекбоксы. Картинка превью у всех страниц одна.

## Главная

Главная — это заметка `index` в корне. `title` там — имя крупно наверху, первый абзац — подзаголовок под ним.

## Важно

Репозиторий на GitHub публичный. Черновики и папку `private` сайт не показывает, но на GitHub их текст виден всем. Личное держи в другом хранилище.
